## 🌟 專案簡介 (Introduction)

**《終極爆能卡牌戰》** 是一款專為**實體展覽、互動導覽與網頁極速體驗**所打造的單頁式（Single-Page）回合制卡牌對戰遊戲。專案將完整的「一頁式產品展示 Landing Page」與「即時互動對戰平台」無縫整合，無需任何後端伺服器或繁瑣安裝，僅需單一 HTML 檔案即可在任何現代瀏覽器上流暢運行。

## 💡 開發緣由與動機 (Origin & Motivation)

| 維度 | 說明與設計思考 | 
| ----- | ----- | 
| **🎯 專案緣由** | 傳統網頁卡牌遊戲往往受限於龐大的素材載入時間與複雜的規則教學，在展覽或快速演示場景中容易讓體驗者卻步。因此，本專案旨在打造一款「**3 秒看懂規則、10 秒上手對決**」的輕量化互動原型。 | 
| **🔥 核心動機** | 1\. **極致零門檻**：摒棄繁雜的外部套件與建置工具，實現單檔即開即玩（Zero-Dependency Runtime）。  2\. **展覽視覺優化**：針對明亮展場環境，將傳統暗黑風重構為高對比、高質感的**明亮毛玻璃美學（Bright Glassmorphism）**，大幅提升螢幕可視性。  3\. **演示可控性**：為現場展示人員設計「無痕雙觸發彩蛋」，確保在有限的演示時間內能完美呈現勝利特效與遊戲完整流程。 | 

## ✨ 核心遊戲特色 (Key Features)

* **🃏 3 選 1 動態抽牌機制**：每回合系統自動提供 3 張精選隨機卡牌，當手牌耗盡或結束回合時立即補滿，確保戰鬥節奏明快、絕不卡手。

* **🛡️ 獨立護盾優先扣抵系統**：完整的傷害計算邏輯，所有攻擊傷害皆會優先扣除目標護盾值，溢出傷害才會削減生命值（HP）。

* **💥 10 費絕殺大招卡組**：內建高耗能逆轉卡牌，兼具毀滅性輸出與攻守一體的「神聖護域」，帶來極致的視覺震撼與晃動回饋（Screen Shake）。

* **🤖 節奏化平衡型 AI**：對手具備 35 HP 與動態行為邏輯，會根據自身能量與血量狀態，在「普通輕攻」、「殘血加盾防守」與「10 費大招爆發」之間智慧切換。

* **🎆 全螢幕 Canvas 物理煙火**：獲勝瞬間觸發獨立畫布渲染的多彩粒子煙火特效，營造滿滿的儀式感與成就感。

* **🤫 雙觸發無痕開發者彩蛋**：UI 介面完全隱藏測試按鈕，展示人員可透過靜默監聽的鍵盤熱鍵或隱藏觸控區，隨時發動 20 點神聖傷害控場。

## 🚀 專案演進歷程 (Development Roadmap)

本專案歷經多個版本的迭代與實測調校，逐步從基礎邏輯演進為展覽級完成品：

* \[x\] **Phase 1：視覺與核心規則建立**

  * 確立 `30 HP / 15 Energy` 的能量池架構與 3 張手牌自動補充機制。

  * 建立回合制戰鬥日誌（Battle Log）即時戰報系統。

* \[x\] **Phase 2：卡牌機制與數值平衡優化**

  * 引入護盾優先扣抵演算，並將 10 費大招擴充為「攻擊、治療、雙防」三系並存。

  * 經歷「極弱展示版 (30 HP)」➔「高難度魔王版 (50 HP)」➔ 最終定案為「**節奏平衡版 (35 HP)**」，兼顧挑戰性與遊戲樂趣。

* \[x\] **Phase 3：明亮視覺重構與無痕彩蛋整合**

  * 為適應明亮展場環境，將整體 UI 重構為 **Bright Glassmorphism（明亮毛玻璃風格）**。

  * 移除所有破壞沉浸感的測試按鈕與文字提示，整合全螢幕 Canvas 煙火動畫與靜默觸發機制。

## 🛠️ 技術架構與規格 (Tech Stack & Specs)

* **核心架構**：純原生 `HTML5` + `Vanilla JavaScript (ES6+)`，零框架依賴，確保極致載入速度。

* **樣式引擎**：整合 `Tailwind CSS (CDN)` 與自訂 CSS3 關鍵影格動畫（Keyframes），實現卡牌懸浮、呼吸光效與受擊震動回饋。

* **圖形渲染**：原生 HTML5 `<canvas>` 2D 物理粒子系統，實現勝利煙火的重力與透明度衰減演算。

* **隱私與安全**：純前端本地運算，無任何外部 API 請求、無 Cookie 追蹤、無個人資料蒐集。

## 🎮 快速啟動與部署 (Quick Start)

1. **下載專案檔案**：
   將本儲存庫中的 `index.html` 下載至本地端，或使用 Git 複製專案：

   ```
   git clone https://github.com/anonymous-dev/ultimate-energy-card-battle.git
   
   ```

2. **立即運行**：
   直接雙擊 `index.html`，使用任一現代瀏覽器（Chrome、Edge、Safari、Firefox）開啟即可開始對戰。

3. **GitHub Pages 一鍵部署**：
   前往儲存庫的 `Settings` ➔ `Pages`，將 Source 設定為 `main` 分支根目錄，即可獲得專屬線上展覽網址！
